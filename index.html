Every pull request a GitHub user has sent to somebody else's project, and what became of it. Type a username; the address bar becomes a link you can share.

Slow, or asked to wait? Add a token. GitHub allows ten unsigned searches a minute and sixty plain requests an hour. A fine-grained token with no permissions at all lifts both. It stays in this tab and is sent only to api.github.com.
